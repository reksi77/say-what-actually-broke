One line of software error copy that tells the brutal truth about what went wrong — and makes you laugh on a single read. This entry's line is a session-expiry message with a twist: the session expired *while the user was reading the sentence that tells them so*. It names the real failure in plain words, tells the user exactly what to do next (sign in again), and reassures them their work is saved.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (override with `OUTPUT_DIR`).
